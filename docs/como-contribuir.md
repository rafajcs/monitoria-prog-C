# Como Contribuir

A apostila e o material de monitoria são projetos em constante evolução.

1. Identifique um erro, sugestão ou conceito que gerou dúvidas durante a aula.
2. Crie uma branch para trabalhar na melhoria (`git checkout -b fix/explicacao-ponteiros`).
3. Realize commits pequenos e descritivos:
   - `feat(apostila): adiciona introdução do capítulo 2`
   - `fix(apostila): corrige erro de digitação`
   - `docs: atualiza documentação de compilação`
4. Teste todos os códigos adicionados (`gcc arquivo.c`).
5. Faça o pull request.
